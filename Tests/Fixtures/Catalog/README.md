# Catalog responses

Captured from the public, unauthenticated F1 TV `2.0/R/ENG/WEB_HLS` page API
on September 29, 2026. These fixtures cover Home, Shows, Documentaries,
Formula 2, Formula 3, F1 Academy, Supercup, the Azerbaijan weekend, Season,
and Archive. Responses retain their real layout identifiers, artwork references,
actions, metadata, and schedule groups. User records are removed; no request
headers, account credentials, cookies, or entitlement tokens are included.
The fixtures are static: menu ordering and editorial content on the service
will change over time. Tests do not fetch the network.

`menu.json` retains the public backend labels, ordering, metadata used to exclude Search/My List, and destination actions. It contains no account or authorization data.
